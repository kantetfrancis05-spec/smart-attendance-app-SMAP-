SMAP — Smart Attendance App

Project Overview

SMAP is a secure university attendance verification system designed to reduce attendance fraud and improve the reliability of classroom attendance records.

Core Features

- NFC student check-in
- Bluetooth Low Energy (BLE) classroom presence verification
- Facial verification
- Rule-based attendance decision engine
- Independent risk and anomaly detection engine

Development Strategy

Each verification method will operate as an independent module, providing evidence to the attendance engine.

Initial Target

Build a working Flutter application, then integrate and test each verification module progressively.
